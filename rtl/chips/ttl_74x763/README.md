# ttl_74x763 — Octal buffer/line driver, inverting, complementary enables (OC)

Inverting counterpart of [ttl_74x741](../ttl_74x741/README.md) /
[ttl_74x757](../ttl_74x757/README.md): one bank gated by an active-low
OE, the other by an active-high OE; both produce the bitwise complement
of their inputs.
