# ttl_74x700 — Octal dRAM driver, inverting (3-state)

Logically identical to [ttl_74x240](../ttl_74x240/README.md). The
SN74S700 is the DRAM-optimized version with controlled output impedance
for driving address/control lines into multiple DRAM loads; the
impedance/drive physics is not part of synthesizable RTL.
