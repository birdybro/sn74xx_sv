# ttl_74x652 — Octal bus transceiver/register, non-inverting (3-state)

Non-inverting twin of [74x651](../ttl_74x651/README.md): same `gab` /
`gba_n` dual-enable control, same SAB/SBA mux selecting real-time vs
stored, same posedge CAB/CBA storage clocks. Output is the chosen source
value directly (no inversion).
